# Pipeline preuves commerciales

Objectif investisseur : obtenir 2-3 lettres d'interet signees ou au moins 1 pilote payant avant demarchage fort.

## Ce qui compte comme preuve

- Lettre d'interet signee : document signe par un prospect identifie, avec cas d'usage, volume estime et prochaine etape.
- Pilote payant : bon de commande, facture ou accord signe avec montant, duree, perimetre et criteres de succes.
- Pilote en cours : acces cree, credits ou forfait paye, usage mesurable dans l'admin.

## Suivi dans le produit

Page : `/admin/enterprise`

Champs suivis :

- statut commercial ;
- etape commerciale ;
- montant pilote payant ;
- date cible ;
- prochaine action ;
- lien vers document signe ;
- admin ayant qualifie la demande.

## Regle de due diligence

Ne jamais presenter un template, une conversation ou un prospect non signe comme LOI signee. La data room doit distinguer clairement :

- `template` ;
- `en discussion` ;
- `signe` ;
- `paye`.
