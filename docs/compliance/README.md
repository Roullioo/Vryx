# Vryx Compliance Pack

Last updated: 2026-05-23

This folder turns Vryx compliance into a diligence-ready package for enterprise buyers. It is not legal advice and must be validated by counsel or a DPO before contract signature, but it gives sales, product and engineering a concrete baseline.

## Documents

| File | Purpose |
| --- | --- |
| `01-gdpr-processing-register.md` | GDPR processing register: purposes, data categories, legal bases, recipients and retention. |
| `02-data-retention-and-deletion-policy.md` | Retention periods, customer deletion flow, no-retention mode and evidence requirements. |
| `03-security-controls-and-access-logs.md` | Encryption, access logs, admin controls, worker controls and audit evidence. |
| `04-datasets-models-and-ai-use-policy.md` | Dataset handling, model licensing, sensitive-sector safeguards and prohibited use. |
| `05-enterprise-contract-checklist.md` | Checklist for DPA, worker terms, model terms, security appendix and incident response. |

## Enterprise Readiness Target

Before selling to regulated buyers such as law firms, automotive, industry, health, finance or defense-adjacent enterprises, Vryx should be able to provide:

- GDPR processing register;
- DPA and subprocessors list;
- retention and deletion policy;
- no-retention mode description;
- security architecture and access logging policy;
- encryption in transit and at rest statement;
- dataset management policy;
- model usage and licensing policy;
- worker terms and confidentiality obligations;
- incident response procedure.
